## Failure Injection

SIGKILL: seven distinct actual restore checkpoints (before/after candidate validation, after old-root rename, after candidate publication, before/after final validation, before COMPLETE commit). A is physically destroyed for every case. Recovery runs in a newly spawned OS process using durable journal/root identity proof, reaching a complete validated B. An additional active Task controller SIGKILL proves fresh S2 recovery ends the same Run INTERRUPTED; restored history does not replay it. Valid official snapshots exclude active Run/resource states, so an active archive is not fabricated to bypass admission.

ENOSPC: actual OS write exhaustion on a private bounded 32 MiB HFS+ disk image. Default production free-space policy first rejects the small volume; only the internal test minimum is then lowered so late writes can genuinely hit ENOSPC. Backup fails with DISK_BUDGET_EXCEEDED, original source/prior READY snapshot remain valid, and backup succeeds after filler removal. The exact private mount is ejected. Separately labelled injected-errno and lowered-quota/preflight cases supplement this physical proof.

Tampering / Wrong Key: actual authentication failures for header/ciphertext/tag/truncation and wrong passphrase, corrupt manifest/domain assets. No successful partial import/restore, secret output or live-root overwrite.
Missing Source: official backup/readiness and actual candidate execution refuse missing source with zero Attempts. Missing Git objects/invalid admin identity fail closed, without reset or reclone.
Ownership: unknown destination, root symlink/replacement, owner mismatch and unknown journal retain unknown bytes and prevent false READY/COMPLETE.
Active Execution: real Shell and freshly installed managed Node Tasks hold Workspace/Config/Node ownership; actual Build EX succeeds before/after and is RUNTIME_BUSY during the managed child. Short backup is BUSY with no successful snapshot; QUIESCING drains the actual child/cleanup and then publishes a terminal consistent snapshot. No secret injection or temporary link is captured.

Qualification-output privacy: raw assertion actual/expected and child output are withheld by a status-only reporter. A deliberate secret-bearing failed child still exits 1 and reports safe error/count/location while no sentinel reaches recorded/public output. Independent A/B worker failures use the same safe-code/location discipline. Safe detailed facts and evidence hashes remain in private case records.

Two implementation defects were fixed from actual failing evidence:

| Defect | Minimal correction and regression |
| --- | --- |
| Fresh Git Task used old SQL commit after a verified local-only commit and skipped indefinitely | Task create/update publish physically verified HEAD in the same held-lease mutation transaction; restore publishes verified repaired HEAD. Historical/queued snapshots are unchanged. A real regression proves old tickets still skip, new Task executes current HEAD, and failed CAS cannot publish metadata. |
| QUIESCING BackupError.code was not recognized by the candidate's error_code-only boundary | A candidate-only typed normalizer preserves known BackupError pause codes. Unknown errors remain errors. Real engine.wait spans QUIESCING/drain and backup succeeds after actual cleanup. |

The first raw-harness v9 run hit Darwin's Unix socket pathname bound because its temporary prefix was too long; a shorter owned private prefix fixed that infrastructure setup and all 190 cases were rerun without assertion changes. A pre-qualification Git fixture accidentally staged the reserved owner marker; staging was restricted to explicit user files while retaining exact status/index assertions. Neither fixture failure is reported as a successful disaster recovery.
